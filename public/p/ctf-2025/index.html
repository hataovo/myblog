用另一种方法

首先依然是$dp \cdot e \equiv 1 \mod (p-1)$，$d \cdot e = 1 + k \cdot (p-1)$我们利用费马小定理$a^{p-1} \equiv 1 \mod p$，构造$a^{dp \cdot e} \equiv a \mod p$，则$p | (a^{dp \cdot e}-a)$，和n求个gcd即可求出p，一般a取2就行

另外注意一点，直接算pow(a, dp * e)不行，没有模数，算出来的数太大了，而且耗时太长，我们取模数n即可，因为

$$ k \cdot p = a^{dp \cdot e}-a = ( a^{dp \cdot e} \mod n) + t \cdot n -a $$

把t*n移到左边，p依然整除pow(a, dp * e, n) - a，

最后，这个题的密文给的就是个数字，直接解就行

class Key:
    def __init__(self):
        self.seed = randbytes(msg_len)

    def generate(self):
        self.seed = self.seed[offset:] + self.seed[:offset]
        return self.seed


def pad(msg):
    pad_len = msg_len - len(msg)
    return msg + pad_len * long_to_bytes(pad_len)


def encrypt(msg, key):
    cipher = xor(pad(msg), key)
    return b64encode(cipher)


def main():

    key = Key()
    cur_key = key.generate()
    cipher1 = encrypt(plaintext, cur_key)

    while True:

            menu()

                    print(f"[!] 输入消息过长，最长为 {msg_len} 字节\n")

                cipher = encrypt(msg, cur_key)

def AMM(o, r, q):
    # o^(1/r) mod q

        '\n----------------------------------------------------------------------------------'

    while p ^ ((q - 1) // r) == 1:
        p = g(random.randint(1, q))
    print('[+] Find p:{}'.format(p))
    t = 0
    s = q - 1
    while s % r == 0:
        t += 1
        s = s // r
    print('[+] Find s:{}, t:{}'.format(s, t))
    k = 1
    while (k * s + 1) % r != 0:
        k += 1
    alp = (k * s + 1) // r
    print('[+] Find alp:{}'.format(alp))
    a = p ^ (r**(t - 1) * s)
    b = o ^ (r * alp - 1)
    c = p ^ s
    h = 1

        c = c ^ r
    result = o ^ alp * h
    end = time.time()
    print("Finished in {} seconds.".format(end - start))
    print('Find one solution: {}'.format(result))
    return result

def wiener_attack(e, n):
    cf = continued_fraction(e / n)
    convergents = cf.convergents()
    for conv in convergents:
        k = conv.numerator()
        d = conv.denominator()
        if k == 0:
            continue
        if (e * d - 1) % k != 0:
            continue
        phi = (e * d - 1) // k
        b = n - phi + 1
        discriminant = b ^ 2 - 4 * n
        if discriminant >= 0:
            sqrt_disc = discriminant.sqrt()
            if sqrt_disc in ZZ:
                p = (b + sqrt_disc) // 2
                q = (b - sqrt_disc) // 2
                if p * q == n:
                    return d, p, q
    return None

记$HPe = Hv = S^{-1}c = y$，$v = Pe$，即$Hv = y$

H是校验矩阵，对于任一码字$c \in C$，当有$Hc = 0$，我们可以先求一特解v0($Hv_0=y$)，其可视为接收向量，从上面可以看出其不是一个有效的码字(y≠0)，由于解不唯一，可表示为$v = v_0 + c, c \in C$，接下来利用sagemath中内置的 Berlekamp–Welch algorithm可以实现: $\text{给定 } r = c + e' \text{, 其中 } c \in C \text{, 且 } e' \text{ 的重量} \leq t \text{, 输入接收向量}r,\text{可以找到码字 } c$

这里有的是$v = v_0 + c, c \in C$，故v-v0是一个码字，那v0-v也是一个码字，因为$H(v_0-v) = -H(v-v_0) = -0 = 0$

《辫子群上的公钥加密算法》 本题考察了辫子群上的公钥加密算法， P-BPKE问题

辫子群是一个 Artin 群，属于非交换群，具有 $n$ 个生成元 $a_1, \dots, a_n$ 的辫子群记为 $B_n$

对于给定的指标 $i$，可以将 $B_n$ 分为左子群和右子群：$LB_l = \{a_1, \dots, a_{i-1}\}, \quad RB_r = \{a_{i+1}, \dots, a_n\}$

辫子群具有以下基本性质：

当 $|i-j| \geq 2$ 时，$a_i a_j = a_j a_i$；

当 $|i-j|=1$ 时，$a_i a_j a_i = a_j a_i a_j$。

利用上述交换性质，可以定义辫子的唯一 Garside 规范形。两个具有相同 Garside 规范形的辫子被视为同一个辫子。本题中的crash函数即用于将辫子化为其 Garside 规范形

辫子就是辫子群中的元素，对于辫子群上的公钥加密算法 BPKE2 如下

密钥生成

私钥：辫子对 $(x_1, x_2) \in LB_l \times LB_l$

公钥：辫子对 $(a, b)$，其中 $a \in B_n$，$b = x_1 a x_2$

加密过程

设明文为 $M \in \{0,1\}^k$，使用的散列函数为 $H: B_n \to \{0,1\}^k$

随机选择 $(y_1, y_2) \in RB_r \times RB_r$

计算密文 $(c, d)$：$c = y_1 a y_2, \quad d = H(y_1 b y_2) \oplus M$

解密过程

给定密文 $(c, d)$，计算明文：$M = H(x_1 c x_2) \oplus d$

正确性证明 因为 $(x_1, x_2) \in LB_l \times LB_l$，$(y_1, y_2) \in RB_r \times RB_r$，所以有交换性：$x_1 y_1 = y_1 x_1, \quad x_2 y_2 = y_2 x_2$

于是：

$$ H(x_1 c x_2) \oplus d = H(x_1 (y_1 a y_2) x_2) \oplus [H(y_1 b y_2) \oplus M] = H(y_1 x_1 a x_2 y_2) \oplus H(y_1 b y_2) \oplus M = H(y_1 b y_2) \oplus H(y_1 b y_2) \oplus M = M $$

rsa4

已知dp, dq, p, q，e未知 首先$c^d \equiv m \pmod{n} $，可得方程组

$$ \begin{cases} c^d \equiv m_1 \pmod{p} & (1) \\ c^d \equiv m_2 \pmod{q} & (2) \end{cases} $$

又$ dp \equiv d \pmod{p-1},\quad d = dp + k(p-1) $，所以$c^d \equiv c^{dp + k(p-1)} \equiv c^{dp} \pmod{p} $

dq同理，可得方程组如下，据此可以计算出m1和m2

$$ \begin{cases} c^{dp} \equiv m_1 \pmod{p} \\ c^{dq} \equiv m_2 \pmod{q} \end{cases} $$

然后回去看第一个方程组，由(1)可得$c^d = m_1 + k \cdot p $，两边模q可得$m_2 \equiv m_1 + k \cdot p \pmod{q}$，可以由此求出$k \equiv (m_2 - m_1) \cdot p^{-1} \pmod{q}$，至此c的d次幂求出来了，n已知，模n即可得到m

def wiener_attack(e, n):
    cf = continued_fraction(e / n)
    convergents = cf.convergents()
    for conv in convergents:
        k = conv.numerator()
        d = conv.denominator()
        if k == 0:
            continue
        if (e * d - 1) % k != 0:
            continue
        phi = (e * d - 1) // k
        b = n - phi + 1
        discriminant = b ^ 2 - 4 * n
        if discriminant >= 0:
            sqrt_disc = discriminant.sqrt()
            if sqrt_disc in ZZ:
                p = (b + sqrt_disc) // 2
                q = (b - sqrt_disc) // 2
                if p * q == n:
                    return d
    return None

rsa7

公式推导，已知

$$ c_1 \equiv (3p + 7q)^{e_1} \mod N \\ c_2 \equiv (2p + 5q)^{e_2} \mod N $$

变形如下

$$ c_1^{e_2} \equiv (3p + 7q)^{e_1\cdot e_2} \mod N \\ c_2^{e_1} \equiv (2p + 5q)^{e_1\cdot e_2} \mod N $$

同余号右边可以二项式定理展开，交叉项模N就没了，只剩下两项

$$ c_1^{e_2} \equiv (3p)^{e_1\cdot e_2} + (7q)^{e_1\cdot e_2} \mod N \\ c_2^{e_1} \equiv (2p)^{e_1\cdot e_2} + (5q)^{e_1\cdot e_2} \mod N $$

再配一个系数把p或者q消掉一个

$$ c_1^{e_2} \equiv k_1 \cdot p^{e_1\cdot e_2} + k_2 \cdot q^{e_1\cdot e_2} \mod N \\ c_2^{e_1} \equiv k_3 \cdot p^{e_1\cdot e_2} + k_4 \cdot q^{e_1\cdot e_2} \mod N \\ $$

给上面的式子两边乘一个(k1_inv * k3)然后做差，最后用gcd求即可

参考博客，给了一种从未设想的道路，由$p \cdot q = n$得$p \cdot (p+q-p) = n$，然后处理一下不完全正确的(p+q)，把正确的部分提取出来，代入，得到一个关于p的方程，可以解出不完全正确的p，也就是高位正确的p，然后和rsa8一样恢复p就结束了

具体地，(p + q)_new = p + q + 2 * noise + 1 - pow(noise, 2)，noise是40位的，则noise平方是79或80位(记为t位)，2*noise是41位的，注意noise的平方是要减去的，如果不发生借位，那么最多就影响t位，如果发生借位，那么最后完整的p+q右移t位后，实际上少了个1，要补上

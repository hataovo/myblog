RSA剪枝类型题目

前言

有时候会遇到这种类型的RSA题目，额外信息只给了p和q的异或值，要从中恢复出p和q，这种情况一般采用递归函数去剪枝搜索。本文简单陈述原理，然后附几道题加深理解

原理简述

比如p和q都是512位的素数，那么p和q的最高位一定都是1，我们以此为初始条件进行搜索，若p^q的下一位为1，则有两种可能，p+‘0’,q+‘1’或p+‘1’,q+‘0’，这样递归去搜索

剪枝条件有两个：

若p和q的剩余位全补0，那么p*q一定小于n，此时若p*q>n，则return

若p和q的剩余位全补1，那么p*q一定大于n，此时若p*q<n，则return

结束条件：

已经搜索出的长度等于目标长度，且p*q=n

当然，上面只是最基本的一种情况，实际题目中变化很多，可能给的不是p^q，而且搜索顺序也不只一种，上面是从高位向低位搜索，也能从低位向高位搜索，或者从两边向中间…

个人感觉难点在具体的递归函数实现上，需要多写多练

从低向高

显然的，p和q的最低位也一定都是1，从低位开始搜索，依然是利用p^q，直白的想法就是用和上面一样的剪枝条件去做，但实际上，因为是从低位开始搜的，高位全填0基本上可以说乘积一定比n小，全填1则基本上一定比n大，因此剪不掉多少分支，时间可能会用很长很长

换一种方法，此时若p和q都搜索出了l位，则p*q和n的低l位一定相等，这就是剪枝条件，脚本稍加修改即可

def search(p, q):

    l = len(p)
    if l == 1024:
        if int(p, 2) * int(q, 2) == n:
            return p, q
        else:
            return

    if int(p, 2) * int(q, 2) % (2**l) != n % (2**l):
        return

    result = None

    if binpq[1024 - 1 - l] == '0':
        result = search('0' + p, '0' + q)
        if not result:
            result = search('1' + p, '1' + q)
    else:
        result = search('0' + p, '1' + q)
        if not result:
            result = search('1' + p, '0' + q)

    return result

def search(p, q):

    l = len(p)
    if l == 748:
        if int(p) * int(q) == n:
            return p, q
        else:
            return

    if int(p) * int(q) % (10**l) != n % (10**l):
        return

    result = None

    result = search('4' + p, '4' + q)
    if not result:
        result = search('4' + p, '7' + q)
        if not result:
            result = search('4' + p, '8' + q)
            if not result:
                result = search('7' + p, '4' + q)
                if not result:
                    result = search('7' + p, '7' + q)
                    if not result:

                            if not result:
                                result = search('8' + p, '7' + q)
                                if not result:
                                    result = search('8' + p, '8' + q)

    return result

Dec 21, 2025
阅读时长: 12 分钟

前言

本文记录了一些泄露高位/低位的题目

核心方法是coppersmith

原理简述

1. coppersmith方法small_roots()参数的设置，摘自 [参考1]

X:所求根的上界

beta(β): 限定因子，满足$b >= N^{\beta}$ ，默认值为1 (所以此情况下b = N)

(找到 f(x)=0 的一个解，使它在模n的某个因子时成立，此时这里说的某个因子即为b，在rsa中n = p * q，只有两个因子，故此时的b即p或q。一般我们遇到的题中p,q位数都是相等的，故beta可取0.5，但更多情况下我们并不知道p,q哪个大，所以保险起见beta通常取0.4)

epsilon(ϵ): 限定因子，默认值为$ \beta / 8$，epsilon越小，耗时越长

2. 最简单的类型例如rsa8，直接泄露p或q的高位/低位，可以直接构造coppersmith

3. 模板化的d高位泄露打法

$d = d_{high}\cdot 2^{lowbits} + d_{low}$，$d_{high}已知，lowbits是d_{low}的比特位数$，则由$ed = 1+k\cdot phi$，可得$e(d_{high}\cdot 2^{lowbits} + d_{low})-1 = k(n-(p+q)+1)$，变形可得$kn =e(d_{high}\cdot 2^{lowbits} + d_{low})-1+k(p+q-1) $，同时除n，$k = \frac {e\cdot d_{high}\cdot 2^{lowbits}}{n} + \frac{d_{low}}{n}-\frac {1}{n}+ \frac {k(p+q-1)}{n} $，观察比特位数，发现右边除了第一项，除以n后都非常小，即$k \approx e\cdot d_{high}\cdot 2^{lowbits}//n $，具体做法是给右边+i，遍历[0,+1]即可可以求出k的值

求出k之后下一步，忽略掉$d_{low}$，由$ed = 1+kn-kp-kq+k$，得$edp = p+knp-kp^2-kn+kp$，代入数据可以求出p的高位(此时求出的p也大概低$lowbits$位是不准确的)，最后回到 [2] ，copper恢复p

4. 自然的想法，d的低位泄露怎么打？

显然和上面一模一样行不通了，因为同样的方法已经求不出k了，结合了一个例子放在[T3]叙述了

def encode(data, marker, passphrase=None, randfunc=None):
    """Encode a piece of binary data into PEM format.

    Args:
      data (byte string):
        The piece of binary data to encode.
      marker (string):
        The marker for the PEM block (e.g. "PUBLIC KEY").
        Note that there is no official master list for all allowed markers.
        Still, you can refer to the OpenSSL_ source code.
      passphrase (byte string):
        If given, the PEM block will be encrypted. The key is derived from
        the passphrase.
      randfunc (callable):
        Random number generation function; it accepts an integer N and returns
        a byte string of random data, N bytes long. If not given, a new one is
        instantiated.

    Returns:
      The PEM block, as a string.

    .. _OpenSSL: https://github.com/openssl/openssl/blob/master/include/openssl/pem.h
    """

    if randfunc is None:
        randfunc = get_random_bytes

    out = "-----BEGIN %s-----\n" % marker
    if passphrase:
        # We only support 3DES for encryption
        salt = randfunc(8)
        key = PBKDF1(passphrase, salt, 16, 1, MD5)
        key += PBKDF1(key + passphrase, salt, 8, 1, MD5)
        objenc = DES3.new(key, DES3.MODE_CBC, salt)
        out += "Proc-Type: 4,ENCRYPTED\nDEK-Info: DES-EDE3-CBC,%s\n\n" %\
            tostr(hexlify(salt).upper())
        # Encrypt with PKCS#7 padding
        data = objenc.encrypt(pad(data, objenc.block_size))
    elif passphrase is not None:
        raise ValueError("Empty password")

    # Each BASE64 line can take up to 64 characters (=48 bytes of data)
    # b2a_base64 adds a new line character!
    chunks = [tostr(b2a_base64(data[i:i + 48]))
              for i in range(0, len(data), 48)]
    out += "".join(chunks)
    out += "-----END %s-----" % marker
    return out

公式推导，我们有两条式子，$q\cdot inv \equiv 1 \mod p$以及$e \cdot dq \equiv 1 \mod (q-1)$

变形，$q\cdot inv = 1+k_1 \cdot p$，往q上靠，$q^2 \cdot inv = q + k_1 \cdot n$，即$q^2\cdot inv \equiv q \mod n$

第二个式子，$e \cdot dq = 1 +k_2 \cdot (q-1)$，即$k_2 \cdot q = e \cdot dq - 1 +k_2$，记等号右边为t，我们把这个等式代入上面的同余式子，即两边同乘一个k2的平方，得$(k_2q)^2 \cdot inv \equiv k_2^2 \cdot q \mod n$，即$t^2 \cdot inv \equiv k_2 \cdot t \mod n $

现在看一下最终的式子，k2是可枚举的，inv是已知的，t中有低位泄露的dq，我们可以打copper

具体地，$t = e(dq_{high}+dq_{low})-1+k_2$，其中$dq_{high} = x\cdot 2^{48}$，dq求出来以后这题就结束了

最后参数设置时看原理简述中，构造的多项式是模n上的，故beta=1，epsilon从1/8开始往下调(以前怎么没注意过这个参数…)epsilon默认值跑不出结果，0.1也不行，0.09可以，0.08也可以
